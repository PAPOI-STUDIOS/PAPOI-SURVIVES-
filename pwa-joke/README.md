# Joke Burst PWA

Una PWA simple y funcional para generar chistes aleatorios desde la API pública de JokeAPI.

## Ejecutar localmente

1. Abre la carpeta `pwa-joke`.
2. Sirve la carpeta con un servidor local, por ejemplo:
   - `python -m http.server 8000`
3. Navega a `http://localhost:8000`.

## Características

- Generador aleatorio de chistes
- API externa (`https://v2.jokeapi.dev`)
- Botón para copiar el chiste
- PWA instalable
- Service worker para caché offline básico

## Nota

El repositorio original tiene un juego grande; esta app se dejó en una carpeta separada para no romper la estructura actual.
